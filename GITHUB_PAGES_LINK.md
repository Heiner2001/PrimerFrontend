## 🔄 Actualizar la Aplicación

Si haces cambios en el código y quieres actualizar el sitio:

```bash
# 1. Hacer cambios en el código
# 2. Navegar a frontend
cd frontend

# 3. Crear nuevo build
npm run build

# 4. Copiar build a raíz
Copy-Item -Path "build\*" -Destination ".." -Recurse -Force
cd ..

# 5. Subir cambios
git add .
git commit -m "Actualizar aplicación"
git push origin gh-pages

# 6. Esperar 1-2 minutos
# La página se actualizará automáticamente
```
